## 关键差异

- QLI1.0存在一整套围绕`HY11`/`HY22`CRM变体的专有预编译产物分发机制(脚本`populate_prebuilt.sh`+manifest`x-quic-distributable`规则+各专有模块下的`crm/noship_common_HY11|HY22`清单文件),用于控制哪些二进制以何种"变体格式"对外/对客户交付。
- QLI2.0中完全没有HY11/HY22或对应CRM变体机制的任何残留痕迹,说明该"预编译产物按CRM变体分发"的模型在新架构下未被沿用——这与output/Code_Composition/Layer_Architecture.md、output/Code_Composition/Patch_Management.md观察到的结论一致:QLI2.0大幅去除了闭源专有组件与配套的私有分发基础设施,转向开源recipe+SRCREV拉取源码构建的模式,不再需要按"HY变体"筛选预编译二进制。
- QLI2.0并非完全没有闭源预编译分发,而是把这件事从"manifest属性驱动的本地脚本打包、按HY11/HY22分发到不同prebuilt目录"改造成了"每个闭源组件的recipe直接从`softwarecenter.qualcomm.com`按组件名+版本/构建日期路径拉取指定预编译包"(`grep -rn "softwarecenter.qualcomm.com" meta-qcom --include=*.bb --include=*.bbappend --include=*.inc`命中多条recipe),分发机制被现代化为标准Yocto recipe fetch模式,不存在能力缺失。

## 影响与风险

- 已确认QLI2.0侧存在替代性的"预编译产物分发"机制(`softwarecenter.qualcomm.com`+组件独立版本化),不是能力缺失,下游若仍依赖QLI1.0的HY11/HY22变体交付形态,需要迁移到新的按组件/构建日期拉取的方式,而不是继续假设有CRM variant标签存在。
- HY11/HY22二者的具体业务差异已通过`release`仓库git历史(2954条commit)与`noship_common_HY11`/`HY22`文件diff坐实:HY11=通用应用处理器fullstack变体,HY22=机器人参考栈(robotics)变体且额外打包蜂窝/调制解调器相关组件;仅"HY"两字母本身的缩写全称,在可访问的commit历史与文件内容里均未找到权威定义。
- 补充追溯"HY"编号的历史起源(而非字面全称):`crm/`目录下历史上实际存在过4个HY变体——`HY11`、`HY22`、`HY31`(改名前叫`HY33`)。2010年commit`7ce9ab4`(Add HY33 variant)/`429fe67`("hy33: Initial noship_common_HY33 for WebOS")显示HY33最初是为WebOS(Palm/HP,froyo时代与Android并存的另一个目标OS)新增的noship清单,随后`3f2123c`("Rename HY33 to HY31 per target team request")说明HY编号由"target team"分配管理、可按需重命名,不是固定语义编码。这说明"HY+两位数字"更像是release/CRM团队内部的目标变体序号(target variant index),挂靠在具体"目标平台/客户线"上按需申请、可重命名,而不是每个字母都对应业务含义的正式缩写——与"HY"本身的字面全称一样,序号背后的分配逻辑同样未在可访问的commit历史中给出书面定义。
- "HY"缩写字面全称的搜索已再次扩展:检索"HY"在"handset"/"hearable"/"hybrid"等常见Qualcomm产品线缩写模式附近的用法,仅命中`x-ship`/`dest-branch`里大量`*-handset.lnx.*`分支名(如`vfw-vpu-handset.lnx.2.0`),这类"handset"分支名与HY11/HY22本身是两套独立的标签体系(一个标注目标产品形态,一个标注CRM交付变体),未见二者存在缩写派生关系。

## 待确认

- **"HY"缩写的权威全称**——两个变体的业务差异已坐实(见上"影响与风险"),HY编号的分配/命名管理方式也已通过HY33→HY31改名史坐实(由release团队的"target team"按需分配、可重命名,不是固定语义编码,见上)。仅剩"HY"两字母字面全称本身:`release`仓库`git log --all --grep`搜索2954条commit(覆盖2009年至今全部历史,含WebOS/HY31/HY33相关commit)、`crm/noship_common_HY11`/`HY22`/`HY31`/`HY33`文件内容,以及"HY"在handset/hearable/hybrid等常见缩写模式附近的用法,均未找到缩写展开或命名背景说明。已确认不在代码库/commit历史可及范围内,需联系Qualcomm release engineering/CRM团队里知悉该命名历史的人当面确认,或查比本次可访问git历史更早(2009年之前)的内部立项文档。
